I've spent more than eight years in production. Compositing, 3D, simulation in Houdini, motion design for brands. Somewhere in there I started writing the tools I kept wishing someone else would write.

That habit turned into Reimagine FX in 2018. It has since released seven Maya plugins and a Nuke diagnostic suite, plus three iOS apps for viewing 3D on a phone (two of them stream live scenes from Maya and Blender). Artists in 79 countries have downloaded the tools.

Most of that software now gets built with AI in the loop. I run coding agents from a command center I wrote myself, and I've connected them to Maya, Houdini, Cinema 4D and Premiere Pro through typed, reviewable tools. I still make the calls. The agents do a lot of the typing.

When the pipeline is the bottleneck, I fix the pipeline.

How I work with agents

  1. 01Typed tools only

    Agents call validated tools with typed inputs. They don't get a raw Python prompt inside a live scene.

  2. 02Explicit permission

    Outbound actions need permission I've given on purpose, either per action or as a written standing rule with limits. A stored login never counts as permission.

  3. 03Evidence before done

    A task closes on tests, audits or a live check. A model saying it's finished doesn't count.

  4. 04Local first

    Speech, models and project data stay on my machine wherever possible. Maya Viewer streams over the local network with no cloud upload and no account.
