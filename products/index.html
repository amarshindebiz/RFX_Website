Maya Plugin
Light Target
A Maya plugin for precise light targeting — point any light directly at any object in your scene instantly.
Get on Gumroad →

Aim any Arnold light at any point in your scene and keep it locked there. Drop a target locator at world origin or snap it to a mesh surface in one click — the light tracks it through an aim constraint. Move the target and the light follows. Set it once and never touch light rotation again.

What's included

  • Single-light workflow — create / snap / reposition the target, hide, show, lock, resize, rename, unlink without deleting, full undo
  • Multi-light workflow — checklist of all Arnold lights, per-light or one shared target for many lights, bulk hide / show / lock / delete
  • Production-ready — targets tracked by UUID (rename-safe), links saved with the scene, dockable panel, auto-refresh, no conflicts with other RFX plugins

Requirements: Maya 2025/2026, Arnold / MtoA 5.5.x+, Windows 10/11. Includes plugin folder, one-click shelf installer and PDF guide.
