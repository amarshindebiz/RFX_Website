# Reframe 1.1 campaign copy

## Gumroad title

Reframe | Multi-Format Composition + Arnold & Redshift Batch Rendering for Maya

## Gumroad description

Reframe is a format-planning and delivery plugin for Autodesk Maya.

Choose from 39 production presets across 12 format families, compare several crops at once, and keep color-coded guides visible in the active camera. Reframe adjusts film aperture instead of changing focal length, so you can protect either vertical or horizontal field of view while moving between landscape, square, portrait, and platform-specific outputs.

Version 1.1 adds Redshift batch delivery beside Arnold. Build one ordered queue, choose the render camera, and send stills or image sequences through the active renderer. Image format, frame extension, padding, and frame range stay synchronized with Maya Render Settings. Sequence jobs are separated into preset-named folders, Escape cancels an active batch, and Reframe restores the scene state after delivery.

Features:

- 39 production presets across 12 format families
- Search, favourites, custom formats, and format inspection
- Multi-format preview with per-guide outside-mask opacity
- Live, color-coded camera guides with compact labels
- Vertical or horizontal FOV lock
- Ordered Arnold and Redshift batch queue
- Still-image and image-sequence delivery
- Per-preset folders for sequence output
- Render camera controls and Render Settings access
- Escape cancellation and scene-state restoration

Included: Reframe plugin folder and installation guide PDF.

Requirements: Autodesk Maya 2025 or newer on Windows 10/11. Arnold delivery requires MtoA. Redshift delivery requires redshift4maya.
