# Luminous systems

Area Light Maps Pro is presented as a lighting instrument, not a texture pack. The image system uses a near-black field, restrained cyan light paths, and hard-edged editorial type. Each frame should feel like a measured studio surface where one controlled source defines the form.

The campaign line, "Light has a shape," carries the hierarchy. Large white type states the idea; blue marks the operative word. Small monospace labels behave like renderer readouts, giving each composition a technical cadence without turning it into a software manual.

Real product evidence stays central. Maya captures sit inside thin frames with their full 2030 x 1724 image visible. They are never cropped, filtered, rotated, tinted, covered by graphics, or rebuilt. Arnold and Redshift appear as equal parts of one workflow, with their native blue and red interface badges left intact.

Map imagery acts as the light source for cover pieces. Circular modifiers extend beyond the canvas edge, creating scale and visual pressure while the left side remains quiet enough for the title. Fine orbit lines suggest direction and falloff rather than decoration.

The set moves from idea to proof: map library, favourites, renderer-aware mixer, renderer-aware linking, rigs, conversion, then a short close. Instagram uses portrait pacing and Gumroad uses the same sequence in a wider, denser frame. The thumbnail reduces the system to icon, title, map, and renderer support so it remains legible at small size.
