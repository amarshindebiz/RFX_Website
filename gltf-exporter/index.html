What it exports

More than geometry.
Your scene, translated.

Built for artists who need Maya assets to arrive in web, mobile, AR, and real-time viewers with the important data still attached.

01 / GEOMETRY

Production mesh data

Exports triangulated geometry with positions, normals, tangents, UVs, optional vertex colors, and multi-material primitive splits.

02 / MATERIALS

Portable PBR

Translates modern Maya shading into glTF metallic-roughness materials with base color, normal, emissive, opacity, occlusion, metallic, and roughness support.

03 / TEXTURES

Texture-ready delivery

Copy external textures or embed them in GLB. Unsupported source formats can be converted, resized, and packed for portable viewing.

04 / HIERARCHY

Transforms preserved

Keeps Maya hierarchy and local matrices, including pivots, shear, and orientation. Flat export mode uses world matrices when needed.

05 / LIGHTS

Punctual lights

Exports supported point, spot, and directional lights through the standard KHR_lights_punctual extension.

06 / FEEDBACK

Clear completion state

Live progress, warnings, export statistics, cancellation, and an unmistakable Done state make delivery easy to verify.

Choose your format

One file or an open package.

GLB

Recommended

A self-contained binary file with geometry, materials, and embedded textures. Best for iPhone, web viewers, sharing, and handoff.

  • Single portable file
  • Embedded images
  • Simple upload and delivery

glTF

A readable JSON scene plus a binary buffer and texture folder. Best when developers need inspectable, replaceable assets.

  • Human-readable scene data
  • External textures
  • Pipeline-friendly structure
Modern shading support
