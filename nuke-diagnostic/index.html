FAQ

Before you add it to your Nuke setup.

Who is this plugin for?

Nuke compositors, compositing supervisors, pipeline TDs, VFX studios, freelancers managing complex shots, lookdev/lighting teams handing CG to comp, and anyone who wants cleaner scripts before review, publish, or render.

Does running diagnostics modify my comp?

No. Normal diagnostics inspect the script and report findings. Diagnostic overlays and note/context tools create temporary nodes only when explicitly requested.

Does it measure exact render time?

The performance profiler uses deterministic heuristics rather than low-level render timing. It is designed to identify render-cost risk, bottleneck nodes, heavy branches, duplicate reads, and output branch cost.

What reports can I export?

The current release supports HTML report export, JSON report export, and performance profile JSON export.

What versions are targeted?

The plugin targets Nuke 15+ and Nuke 16+. Windows is tested. Linux and macOS support depends on studio validation and local Nuke configuration.
