# Ramp Generator campaign copy

## Gumroad description

Ramp Generator is a visual gradient editor for Autodesk Maya 2026.

Build ramps by dragging color stops, start from 100 curated gradients, generate variations by category, sample colors from an image, or bake the result as a PNG up to 4096 px wide. Personal presets stay available between Maya sessions, and preset packs can be moved between artists or workstations.

Version 1.1.0 supports three shader workflows from the same Editor tab:

- Native Maya ramps with place2dTexture setup
- Arnold aiRampRgb with direction controls and scene sync
- Native ramps connected to supported Redshift materials

Choose a shader and input, then press Apply. Batch Apply handles the unique shaders connected to the selected objects. Scene changes are grouped for Maya undo and redo.

Included: Ramp Generator plugin, 100 editable gradients, shelf installer, empty preset library, and a one-page installation guide.

Requirements: Autodesk Maya 2026 on Windows 10/11. Arnold tools require MtoA. Redshift tools require redshift4maya. Redshift mode supports up to eight ramp stops.
