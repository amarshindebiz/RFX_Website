Maya Viewer

Review Maya scenes on iPhone and in AR.

Maya Viewer is built by Amar Shinde at Reimagine Fx to help 3D artists review Autodesk Maya scenes directly on iPhone. It connects to a lightweight Maya Python server and streams scene geometry, materials, textures, cameras, lights, and object statistics into a clean mobile viewer and AR preview.

Free Maya Python plugin required to connect Maya Viewer to Autodesk Maya.

Features

Built for fast Maya scene review

Live Maya scene preview on iPhone

Connect to your local Maya session and inspect scene data from a clean mobile viewer.

AR mode for real-world placement

Place Maya scenes in physical space using AR mode.

Wireframe and texture tools

Inspect meshes, textures, materials, and scene organization.

Maya camera support

Preview composition and framing away from the desktop.

Scene statistics

Inspect mesh, vertex, triangle, and light counts.

Object transform controls

Move, rotate, and scale supported scene objects.

Setup

How it works

Download the plugin

Download the free Maya Viewer plugin ZIP.

Copy to Maya scripts

Copy the plugin into your Autodesk Maya scripts folder.

Run the server

Run the plugin in Maya.

Open Maya Viewer

Launch the iOS app.

Connect

Enter IP, port, and optional PIN.

Review scenes

Inspect your Maya scenes on iPhone and in AR.

import rfx_mayaviewer as mv
mv.start_server(pin="optional-pin")
Requirements

What you need

  • Autodesk Maya on desktop.
  • iPhone or iPad for the app.
  • Same local network recommended.
  • Optional PIN protection supported.
  • Remote access not officially supported.
  • Not a replacement for Arnold rendering.

Privacy Policy

Maya Viewer Privacy Policy

  • Maya Viewer does not collect personal data.
  • No analytics, ads, or tracking.
  • Camera access is used only for AR mode.
  • Local Network access is used only for Maya connection.
  • Scene data remains between your device and Maya session.
  • Reimagine Fx does not store Maya scene data.
